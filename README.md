# C to Verilog: 32-bit Adder with Bambu HLS

My first Verilog project. A simple C function is converted into a hardware
design (Verilog) using the [Bambu](https://release.bambuhls.eu) High-Level
Synthesis tool, then verified with a testbench in Icarus Verilog.

## Project structure

```
src/add.c      C source (the function to turn into hardware)
rtl/add.v      Verilog generated by Bambu (do not edit by hand)
tb/add_tb.v    Self-checking testbench
```

## Requirements

- Linux
- [Bambu 0.9.7 AppImage](https://release.bambuhls.eu)
- Icarus Verilog

## Generate the Verilog

```bash
./bambu-0.9.7.AppImage src/add.c --top-fname=add
```

This produces `add.v` from the C function `add`.

## Simulate

```bash
iverilog -o sim rtl/add.v tb/add_tb.v
vvp sim
```

Expected output:

```
a=5 b=7 result=12
PASS
```

## What I learned

- How HLS turns a C function into a hardware module
- The handshake ports Bambu generates (`clock`, `reset`, `start_port`, `done_port`)
- Writing a self-checking testbench and simulating with Icarus Verilog
